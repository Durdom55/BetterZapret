# BetterZapret
Эта программа не является самим **zapret-discord-youtube**, а всего лишь дополнение к нему
>[!WARNING]
>Анти-вирусы могут помечать .exe файл из релиза, как вредоносный - **это ложное срабатывание**. Происходит это из-за отсутствия какой-либо цифровой подписи, так как я произвожу билд через *auto-py-to-exe*. Вы можете сами сделать билд проекта, скачав исходный код

## Остерегайтесь мошенников
Перед скачиванием или запуском батников запрета, убедитесь, что скачали из оффициального репозитория [Flowseal](https://github.com/Flowseal/zapret-discord-youtube). Скачивая из других источников (тг каналов, сайтов и т.п.), вы рискуете **своей безопасностью**

## Руководство по использованию
1. Для начала скачайте .exe файл из релиза данного проекта или сделайте билд сами
2. Затем скачайте оригинальный запрет от [Flowseal](https://github.com/Flowseal/zapret-discord-youtube)
   
   >[!NOTE]
   >Оригинальный запрет был разработан пользователем [bol-van](https://github.com/bol-van/zapret/tree/master). Flowseal же сделал всё в формате батников

3. Откройте .exe файл от имени администратора, затем выберите нужный батник, нажав на иконку кота слева сверху
   
   <img src="resources/icons_for_readme/PathShowGif.gif" width="222"/>

4. Чтобы включить/отключить запрет нажмите на лампочку
   
   <img src="resources/icons_for_readme/OnOffGif.gif" width="222"/>

   >Во время **включения/отключения** может появиться **командная строка**, не пугайтесь - это **нормально**, для более подробного объяснения смотреть [здесь](#включениеотключение)

## Принцип работы программы
### Старт
  Сначала программа проверяет, запущена ли она от имени администратора
  ```python
  if isadmin() == False:
    tkinter.messagebox.showerror(message="Программа запущена не от имени администратора")
    sys.exit(1)
  ```
  Затем проверяется, запущен ли уже у нас запрет
  ```python
ZapretRun = subprocess.run("sc qc windivert", shell=True)
if ZapretRun.returncode == 0:
    ZaonBg() # Смена фона
    print("zapret vkl") # Для отладки
else:
    print("zapret vikl") # Для отладки
  ```
  ### Добавление батника
  Когда вы добавляете путь к батнику, выполняется метод [PathCreate](BetterZapret.py#L69-94)
  ### Включение/Отключение
  Во время включения выполняется запрос в командную строку, из-за чего она может появиться на секунду
  ```python
  def Zaon():
    ZaonBg() # Смена фона и деталей интерфейса
    os.startfile(path) # Запуск выбранного батника
    print("Zapret vkluchen") # Для отладки
  ```
   Во время отключения также выполняется запрос в командную строку, из-за чего она может появиться на секунду
   ```python
   def Zaoff():
    ZaoffBg() # Смена фона
    os.system("taskkill /im winws.exe") # Выключение запрета
    os.system("sc stop windivert") # Отключение WinDivert
    print("Zapret viklichen") # Для отладки
   ```
